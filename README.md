**\[Made specifically for Shum's Modpack and to work alongside Shum's Additions]**



*This resource pack is meant to add descriptions for a variety of mobs and items in a resource pack. It was made with* [*Item Descriptions*](https://modrinth.com/mod/item-descriptions) *and* [*Field Guide*](https://modrinth.com/mod/field-guide) *in mind.* 



### Contains:

* A name for the new Field Guide category added by Shum's Additions
* Descriptions for [Ribbits](https://modrinth.com/mod/ribbits) entities
* Descriptions for [Ribbits](https://modrinth.com/mod/ribbits) items
* Descriptions for [Critters and Companions](https://modrinth.com/mod/critters-and-companions) entties
* Descriptions for [Faunify](https://modrinth.com/mod/faunify) entities
* Descriptions for [WilderNature](https://modrinth.com/mod/lets-do-wildernature) entities
* Descriptions for [Clutter: Bestiary](https://modrinth.com/mod/clutterbestiary) entities
